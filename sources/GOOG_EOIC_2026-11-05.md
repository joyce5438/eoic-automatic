# Alphabet（GOOG）｜五季企業營運與創新週期

資料截止 2026-11-05；2025 Q3–2026 Q3；金額百萬美元。Google 搜尋廣告由廣告主支付，Google Cloud 由企業客戶支付；搜尋 AI 使用、雲端合約積壓和已認列營收是不同層次。

## 主要判斷

我判斷整體**擴張，Google Cloud 進入加速變現，資本回收暫時滯後**。2026 Q3 Cloud 收入 30,709、年增 102.6%，分部營業利益 11,121，去年同期 3,594；但集團 Q3 資本支出 51,355 超過 OCF 42,290，標準 FCF 為 -9,065。最早轉折可在 2025 Q3 的 Cloud backlog 約 1,550 億美元及收入 15,157 看到，屬事後重建；backlog 並非當季營收或保證不取消的現金。[2026 Q3 財報](https://www.sec.gov/Archives/edgar/data/1652044/000165204426000080/googexhibit991q32026.htm)、[2025 Q3 會議](https://stockanalysis.com/stocks/googl/transcripts/366282-q3-2025/)

## 創新傳導與反證

AI 晶片、資料中心及模型投入 → 企業採用與雲端合約增加 → Cloud 已認列收入及分部營業利益增加 → 集團稅後利益與現金回收（仍待驗證）。AI 服務獨立收入、推論單位成本與留存未單列，Google Cloud 也包含非 AI 服務及設備收入。搜尋 AI 月活與 token 使用能支持採用，不能直接等同增量廣告收入。[官方最新會議](https://abc.xyz/investor/events/event-details/2026/2026-Q3-Earnings-Call-2026-Ujou16CTw9/default.aspx)

最強反證是 Cloud 高速增長和利益大增、搜尋廣告也仍成長，可能在投資期先於現金改善；但 Q3 合併 GAAP 利潤率季降及資本支出超過 OCF，尚不足以把所有 AI 投入判為已回收。

## 資本配置

前九月 OCF 127,149、設備支出 131,953，標準 FCF -4,804。財報另列「收購扣取得現金及無形資產購買」合併 34,103；以設備＋該合併科目作**上限代理**＝166,056／127,149＝130.6%，含無形資產，不能稱為純粹企業收購再投資率。若未拆開企業收購與其他無形資產，依技能公式的精確再投資率留缺值。[Q3 10-Q 現金流](https://www.sec.gov/Archives/edgar/data/1652044/000165204426000084/goog-20260930.htm)

ROIC 的近四季營業利益為 156,976；若以 21% 為正常化假設，NOPAT 約 124,011。2026 Q3 權益 677,549、長債 125,102、現金 56,334，但短債與 2025 Q3 期初非營運投資尚待一致核對；不能用不完整分母計算 ROIC，亦不能將分部 margin 當作 ROIC。

## 改判條件

未來兩至三季，若 Cloud 成長持續、分部與集團毛利改善，且資本支出成長放緩後 FCF 轉正，可上修 AI 投資回收判斷。若 backlog 轉收入變慢、毛利受折舊／成本壓力而 FCF 繼續惡化，則下修。全年設備支出 1,950–2,050 億美元是管理層展望，不是實績。
