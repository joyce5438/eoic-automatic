# EOIC Automatic

企業營運與創新週期分析報告庫 · 37 份報告

線上閱讀：https://joyce5438.github.io/eoic-automatic/

## Structure

- `index.html` - 首頁（支援全文檢索、命中段落預覽與多維度標籤篩選）
- `assets/` - 全站共用樣式（`site.css`）、互動邏輯（`site.js`）與全文檢索索引（`search-index.js`）
- `reports/` - 各公司 HTML 閱讀版報告（`{TICKER}.html`）
- `sources/` - 各公司 Markdown 原稿（`{TICKER}_EOIC_{DATE}.md`）

公開閱讀｜每份報告保留 Markdown 原稿與 HTML 閱讀版；資訊截止日以各份報告為準。
